# Week 2 – Python for Data Analytics

## Internship

**Data Analytics Internship – Next Gen Software Hub Pvt. Ltd.**

## Overview

Week 2 focused on using Python for Data Analytics. The tasks covered Python libraries such as NumPy and Pandas, data manipulation and analysis, and data visualization using Matplotlib and Seaborn.

The main practical project for this week was **Sales Data Analysis**.

## Topics Covered

- Python Basics for Data Analytics
- NumPy
- Pandas
- Data Manipulation
- Data Analysis
- Data Visualization
- Matplotlib
- Seaborn
- Sales Data Analysis

## Project – Sales Data Analysis

The project analyzes sales data to understand product-wise, region-wise, and monthly sales performance.

The dataset contains information such as:

- Date
- Customer ID
- Product
- Region
- Quantity
- Unit Price
- Discount
- Revenue

**Note:** The dataset used for this project is a synthetic/practice dataset because an official company dataset was not provided.

## Data Processing

The Python program performs the following operations:

- Loads the sales dataset using Pandas
- Checks the structure and data types
- Identifies missing values
- Removes duplicate records
- Handles missing numerical values
- Converts numerical columns into appropriate data types
- Calculates revenue
- Performs product-wise analysis
- Performs region-wise analysis
- Performs monthly sales analysis

## NumPy Analysis

NumPy was used to calculate basic statistical values such as:

- Mean quantity
- Minimum quantity
- Maximum quantity

## Pandas Analysis

Pandas was used for:

- Data loading
- Data cleaning
- Data manipulation
- Grouping and aggregation
- Product-wise analysis
- Region-wise analysis
- Monthly analysis

## Data Visualization

The project generates visualizations for:

- Revenue by Product
- Revenue by Region
- Monthly Revenue Trend

The visualizations help understand sales performance and identify important patterns in the dataset.

## Key Results

The analysis produced the following results:

- **Total Revenue:** ₹12,173,110
- **Total Quantity:** 635
- **Average Order Value:** ₹67,628.39
- **Highest Revenue Product:** Laptop
- **Highest Revenue Region:** South
